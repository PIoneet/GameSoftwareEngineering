## 0. 이 문서를 읽는 Claude에게

### 0-1. 우선순위
1. `잠든것의이름_개발지침.txt` — 프로젝트 전체 지침 (기술 방향, 협업 규칙)
2. **이 문서(STORY.md)** — 스토리 관련 모든 판단의 기준
3. 발행된 아티팩트(기획서/퀘스트 트리, v0.1) — 참고용. 이 문서와 다르면 이 문서가 우선

### 0-2. 작업 규칙
- 빌드/실행은 사용자가 직접 한다. Claude는 코드 수정까지만 한다.
- 사용자가 "더 말씀드릴게요"라고 하면 구현하지 말고 스펙을 계속 수집한다.
- 스토리 관련 코드를 쓰기 전에 **§1 세계 규칙**과 충돌하지 않는지 확인한다.
- 이 문서의 ID(`CH_`, `FL_`, `EV_` 등)를 코드/데이터에서 그대로 사용한다.
  새 ID가 필요하면 이 문서에 먼저 추가한 뒤 코드에 쓴다.
- 대사를 새로 쓸 때는 **§10 말투 가이드**를 따른다. 현대 인터넷 슬랭 금지.
- 존재의 이름은 어떤 문자열 리소스에도 전체를 쓰지 않는다. 항상 `■`로 가린다.
- 스토리 내용을 바꿔야 하면 코드보다 이 문서를 먼저 수정하고, 수정 내역을 §16에 남긴다.
- **숨은 변수(§13)는 어떤 UI에도 수치로 표시하지 않는다.** 플레이어는 신호(§13-3)로만 추측한다.
- NPC가 NPC를 해치는 로직은 반드시 §14의 동기 테이블 중 하나에 근거해야 한다. 동기 없는 살해 금지.

## 1. 세계 규칙 (불변식)

모든 스토리 전개와 관련 코드는 아래 규칙을 위반하지 않아야 한다.

| ID | 규칙 | 구현상 의미 |
|----|------|-------------|
| `R1` | 잠든 것은 기억되는 만큼만 존재한다. 악의는 없고, 잊히기를 원한다. 꿈의 찌꺼기가 몬스터를 만든다. | 모든 몬스터 도감 텍스트는 "꿈의 부산물" 설정과 일관 |
| `R2` | 이름의 조각을 **직접 들은** 사람은 세상의 기억에서 지워진다(죽지 않음). | `isErased = true` 전환 이벤트 |
| `R3` | 지움은 축제 노래를 통로로 퍼진다. 노래에 **물든(tuned)** 사람은 지워진 자를 보지도 기억하지도 못한다. 외지인은 볼 수 있다. 이름을 온전히 쥐고도 지워지지 않는 건 물들지 않은 자뿐이다. | `isTuned` 속성, 인식 판정 함수 |
| `R4` | "기억의 끈"(몽석 흉터)이 있으면 물든 사람도 지워진 자를 기억한다. 대가로 본인이 점점 꿈에 물든다. | `hasAnchor` 속성 |
| `R5` | 라벤홀은 이름을 기억하려고 세운 마을. 이름은 축제 노래 가사에 조각나 숨어 있고, **이름의 마지막 조각 = 지명 "라벤홀"**. | 엔딩 A의 대가 근거 |
| `R6` | **죽음은 기억되고, 지움은 기억되지 않는다.** 사망은 원한·소문·공포를 낳는다. 지워진 자의 죽음은 그를 인식할 수 있는 자(외지인, 끈 보유자)에게만 사건이다. | 사망 파급 처리 시 `CanPerceive` 필터 (§14-4) |
| `R7` | **세계는 플레이어가 보지 않아도 움직인다.** 모든 NPC는 동기가 있을 때만 다른 이를 해친다. | 월드 틱 시뮬레이션 (§14) |

### 1-1. 인식 판정 (R3 + R4의 코드화)

```
bool CanPerceive(observer, target):
    if (!target.isErased)      return true
    if (!observer.isTuned)     return true   // 외지인
    if (observer.hasAnchor)    return true   // 기억의 끈
    return false
```

- **렌더링은 항상 주인공 시점**이므로 지워진 자의 스프라이트는 그린다 (주인공은 물들지 않음).
- `CanPerceive == false`인 NPC/동료는 지워진 자를 **대화 대상, AI 타깃, 대사 속 언급**에서 제외한다.
- 지워진 자의 이름 문자열은 `CanPerceive == false`인 UI 문맥(장부, 명부, 물든 NPC 대사)에서 `■■`로 치환하거나 목록에서 제거한다.

### 1-2. 진실의 세 층위 (정보 공개 순서)

| 층 | 공개 시점 | 내용 |
|----|-----------|------|
| 1 | 서장~1막 | 무언가 있고, 사람이 사라지고, 잊힌다 |
| 2 | 2막 | 라벤홀과 축제 노래가 그것을 부르고 있었다 |
| 3 | 3막 | 그것은 잊히길 원한다. 잊게 하려면 누군가 대가를 치러야 한다 |

상위 층의 정보가 그보다 앞선 막의 대사/도감에 노출되면 안 된다.

### 2-5-1. NPC 원형 (`AT_`)

행동은 원형과 성향(`HV_TRAIT`)의 조합으로 결정한다. 원형이 성향의 기본 분포와
소속·적대 관계를 정하고, 개체차는 시드 랜덤인 성향이 만든다.

| ID | 이름 | 소속 | 성향 경향 | 행동 |
|----|------|------|-----------|------|
| `AT_VILLAGER` | 주민 | — | 평범 | 집 주변 배회. 겁이 많으면 위협에서 도망 |
| `AT_FARMER` | 농부 | — | 겁↑ 공격성↓ | 밭을 벗어나지 않음 |
| `AT_MERCHANT` | 상인 | — | 충성↓ | 광장. 소문 허브(§14-6) |
| `AT_SMITH` | 대장장이 | — | 공격성↑ | 자경단 결성 시 참여 |
| `AT_CLERIC` | 성직자 | — | 신앙심↑ | 예배당. 주변 주민의 공포를 낮춘다 |
| `AT_SAINT` | 성인 | — | 신앙심 최대, 공격성 0 | **누구도 해치지 않는다.** 주변의 적대를 가라앉힌다 |
| `AT_VIGILANTE` | 자경단 | — | 공격성↑ 겁↑ | `HV_FEAR >= 60` 이면 소문 표적을 린치 |
| `AT_BANDIT` | 산적 | `FC_BANDIT` | 공격성 최상, 신앙심↓ | 야영지 주변. 단독인 주민·플레이어를 습격 |
| `AT_CULTIST` | 교단 신도 | `FC_CHOIR` | 신앙심↑ 충성↑ | 은신처. 야간에 수도회 병사·밀고자를 암살 |
| `AT_SOLDIER` | 수도회 병사 | `FC_SILENCE` | 충성↑ | 순찰. 정체가 드러난 신도를 체포 |
| `AT_HERBWIFE` | 약초꾼 | — | 중립 | 늪 초입. 어느 편도 아님 |
| `AT_SCHOLAR` | 외지 학자 | — | 겁↑ | 물들지 않음(`isTuned = false`) — 지워진 자를 본다 |

`AT_SAINT` 와 `AT_BANDIT` 은 동기 판정의 양 끝이다. 성인은 `P(attack)` 을 항상 0 으로
만들고, 산적은 동기 기본값이 가장 높다. 그 사이를 나머지가 채운다.

### 2-6. 일반 주민 로스터 (`VL_`)
- 라벤홀 주민은 이름 있는 NPC 20~30명으로 구성 (`VL_001` ~). 각자 직업·가족 관계·거주지를 가진다.
- 가족 관계는 원한 전파에 사용된다 (§14-5).
- **잠입 신도**: 새 게임 시작 시 시드에 따라 `VL_` 중 1~3명을 무작위 교단원으로 지정한다 (에드릭은 고정). 회차마다 누가 신도인지 다르다.

## 7. 엔딩 판정

```
// 3막 제한 시간 초과 시 이 함수에 도달하지 않고 엔딩 D로 강제 진입 (§15-3)
EndingSet GetAvailableEndings(state):
    endings = { A_SEAL, C_DEFY }          // 항상 가능
    if (state.FL_COIN_KEPT
        && state.ST_UNDERSTANDING >= UNDERSTANDING_THRESHOLD_B
        && state.FL_LISTENED)
        endings.add(B_UNDERSTAND)
    return endings
```

- 조건 미충족 엔딩은 선택지에 표시하지 않는다 (회색 표시 X — 존재 자체를 숨김).
- 에필로그는 숨은 변수와 NPC 생존 상태로 추가 변형된다 (§15-4).

### 7-1. 엔딩 내용

**A_SEAL — 다시 재우다**
- 이름을 거꾸로 불러 봉인. 대가: "라벤홀"이 세상의 기억에서 지워짐.
- 주인공은 이름 없는 해안 갈림길에서 깨어남. 이정표가 비어 있음.

**B_UNDERSTAND — 이름을 부르다**
- 주인공이 이름을 온전히 부르고 교감. 세라핀을 이어 새 파수꾼이 됨. 세라핀은 쉼.
- 지워진 자 복귀 (리나, 카엘. 에드릭은 `FL_EDRIC_REDEEMED`일 때 형제 재회 장면).
- 풍년이 끝나고 라벤홀은 평범한 마을이 됨. 축제 노래의 들리지 않던 소절이 사라짐.

**C_DEFY — 맞서 싸우다**
- 이름을 무기로 생존형 최종전 (일정 시간 버티면 종료, 승리 불가).
- 망각이 세계로 번짐. 파티는 "지워진 자를 찾는 모험가단"이 됨.
- 하델: "의뢰인 이름 칸이... 또 비어 있네요."

### 7-2. 동료 에필로그 매트릭스

| 인물 | A_SEAL | B_UNDERSTAND | C_DEFY |
|------|--------|--------------|--------|
| 브람 | 모든 걸 잊고 이유 모를 두 그릇을 푼다. `FL_BRAM_SCAR`면 리나만 희미하게 기억 | 리나를 기억. 한 그릇을 더 퍼서 바다를 향해 놓는다 | 리나를 기억 못 한 채 계속 찾는다 |
| 넬 | 모두를 기억하는 단 한 사람. 갈림길에서 주인공을 기다림 | 흉터가 옅어짐. 처음으로 친구 얼굴을 새기지 않고 잠듦 | 파티와 함께 떠돎 |
| 오르텐 | 왜 썼는지 모르는 원고를 안고 왕도로 | 일지 필사본을 스스로 불태움 | 망각을 기록하는 학자가 됨 |
| 이졸데 | "정화 성공" 보고. 무엇을 정화했는지 모름 | 수도회를 떠나 스승의 길을 걸음 | 전국으로 정화 확대 |
| 테오 | 고향을 잊음 | 라벤홀에 남음 | 수도회 탈영병으로 파티 합류 |

- `FL_NELL_TRUSTED == false`면 모든 엔딩에서 넬의 에필로그 대사를 짧고 쓸쓸한 변형으로 교체.

## 8. 야영 식사 이벤트 (`MEAL_`)

던전밥식 파티 대화 시스템. 요리 = 버프 + 대화.

### 8-1. 규칙
- 발동: 던전 클리어 후 / 지역 이동 중 야영.
- 대사 분기 키: `[ST_ACT] × [파티 구성] × [호감도/플래그]`
- 식사 장면에는 전투·공포 요소를 넣지 않는다. (공포 직후 식사, 식사 직후 공포 — 낙차 설계)
- 요리 재료 = 직전에 잡은 몬스터 소재.

### 8-2. 고정 식사 장면

| ID | 시점 | 요리 | 핵심 | effect |
|----|------|------|------|--------|

- 이 코멘트는 도감 텍스트(`fieldNote`)와 공유 가능.

| 오르텐은 왜 배신할 수 있나? | 30년의 지식 욕망. 파티와의 유대가 약하면 선창자의 제안을 거절할 이유가 없다 | §15-2 |

## 12. 구현 가이드

### 12-1. 권장 데이터 구조 (제안 — 실제 설계 시 조정)

```cpp
// 인물
struct CharacterDef {
    CharacterId id;
    const char* name;
    FactionId   faction;
    bool        isTuned;     // R3
    bool        hasAnchor;   // R4
};

struct CharacterState {
    bool isErased = false;   // R2
    bool inParty  = false;
};

// 게임 상태
struct StoryState {
    Act     act = Act::Prologue;
    int     fragments = 0;
    int     understanding = 0;
    std::bitset<FLAG_COUNT> flags;
    int     affinity[AFFINITY_COUNT] = {};
    Ending  ending = Ending::None;
};

// 이벤트
struct StoryEvent {
    EventId id;
    std::function<bool(const StoryState&)> trigger;
    std::function<void(StoryState&)>       apply;
    DialogueId dialogue;
};
```

- 이벤트 트리거는 **허브 귀환 / 지역 진입 / 보스 격파 / 대화 종료** 시점에만 검사한다 (매 프레임 검사 X).
- 대사 텍스트는 코드에 하드코딩하지 않고 키(`DLG_...`)로 외부 데이터에서 읽는다.
- `CanPerceive()`는 대화 시스템, NPC AI 타깃팅, UI 이름 표시, **사망 파급 처리** 네 곳에서 공통 사용.
- 숨은 변수(`HiddenState`)는 `StoryState`와 **분리된 구조체**로 둔다. UI 코드가 `HiddenState`를 include하지 않도록 한다 (실수로 노출 방지).
- 월드 틱/NPC 에이전트 구조는 §14-7 참고.

### 12-2. 스토리 구현 순서 (개발지침 로드맵 기준)

| 단계 | 스토리 범위 | 필요한 시스템 |
|------|-------------|---------------|
| M4 선행 | 서장 전체 | 대화, 퀘스트 상태, 파티(3인), 식사 이벤트 최소형 |
| M4 | 1막 전체 | 조사(단서 수집), `isErased` + `CanPerceive`, 분기 선택 |
| M5-1 | 2막 지역 1개 (B 광산 권장) | 리나 장면으로 가시성 시스템 검증 |
| M5-2 | 2막 전역 이벤트 | 세력 태그, 호감도, 수도회 |
| M5-3 | 2막 나머지 지역 | 조수 시스템(C), 유생체(A) |
| M5-4 | 3막 + 파이널 | 제한 시간, 보스 2종, 엔딩 판정 |
| M5-5 | 숨은 변수 + 월드 틱 | §13 변수, 오프스크린 틱, 소문 |
| M5-6 | NPC 간 PK + 역할 대체 | §14 동기 판정, §15 대체 표, 엔딩 D |

- 범위 축소가 필요하면 2막 지역을 1~2개로 줄인다. 3막 개방 조건(`ST_FRAGMENTS >= 2`)은 상수로 두어 조정 가능하게 한다.

### 12-3. 구현 시 자주 틀릴 부분
- 지워진 자를 **렌더링에서 숨기면 안 된다.** 주인공 시점이므로 보인다. 숨기는 건 NPC의 인식뿐.
- 2막 지역 이벤트끼리 서로 참조하지 않는다 (순서 무관 보장).
- 엔딩 B 조건 미충족 시 선택지를 **숨긴다** (비활성 표시 아님).
- 도감/대사에서 현재 막보다 높은 진실 층위를 노출하지 않는다.
- 존재의 이름은 어떤 리소스에도 평문으로 두지 않는다.
- 역할 대체(§15-1)를 구현하기 전에 T2 NPC를 사망 가능하게 열면 스토리가 막힌다. **대체 표 구현 → PK 활성화** 순서를 지킨다.
- 월드 틱의 난수는 반드시 세이브에 저장되는 시드 기반 RNG를 쓴다 (재현 가능한 버그 리포트를 위해).

## 13. 숨은 변수 (Hidden Variables)

### 13-1. 원칙
- 플레이어는 이 변수들의 **존재도, 수치도 모른다.** UI/도감/툴팁 어디에도 표시하지 않는다.
- 플레이어는 세계의 변화(§13-3 신호)만 보고 추측한다. → "알아낸 만큼 대응할 수 있다"는 던전밥식 설계를 월드 전체로 확장.
- 일부 초기값과 개인 성향은 **새 게임마다 시드로 랜덤**. 같은 선택을 해도 회차마다 결과가 달라질 수 있다.
- 개발 빌드에서만 디버그 오버레이로 표시 (`#ifdef STORY_DEBUG`).

### 13-2. 변수 목록 (`HV_`)

| ID | 범위 | 초기 | 증가 요인 | 감소 요인 | 임계 효과 |
|----|------|------|-----------|-----------|-----------|
| `HV_FEAR` 마을 공포도 | 0~100 | 10±5 | 실종 +5, 주민 사망(인지된) +8, 자줏빛 하늘 +3, 지워짐 발생 +2 | 의뢰 성공 −3, 마르타 생존 시 일일 −1, 수도회 순찰 일일 −2 | ≥40 야간 상점 폐쇄·물가 상승 / ≥60 **자경단 결성, 린치 시도** / ≥80 주민 도주·교단 입교 급증 |
| `HV_CHOIR` 교단 세력 | 0~100 | 20±5 | 일일 `HV_FEAR/20`, 잠입 신도 생존 수 ×1 | 신도 처치 −3, 성가대 거점 파괴 −15, 에드릭 발각 −10 | ≥50 3막 합창 인원 증가 / ≥70 **마을 내 암살 시작** / ≥90 3막 제한 시간 −30% |
| `HV_SUSPICION` 수도회의 파티 의심도 | 0~100 | 0 (`EV_2_G01` 이후 활성) | 동전 보유 +10, 유생체 살려 둠 +10, 일지 열람 +10, 넬 신뢰 +15, 신도를 살려 보냄 +5 | 신도 처치 −3, 수도회 의뢰 수행 −10 | ≥50 오르텐 소환 심문(1일 이탈) / ≥70 **넬 강제 체포 시도** (신뢰 여부 무관) / ≥90 파티를 정화 대상으로 지정, 3막에 수도회가 파티를 직접 공격 |
| `HV_STIR` 잠든 것의 뒤척임 | 0~100 | 5 | 파편 획득 +10, 축제 밤 +10, 유적 근처 사망 +3/명, 몽석 채굴 +2 | (거의 없음) 유생체 살려 둠 −5 | ≥30 몬스터 스폰 증가 / ≥50 **T3 주민 무작위 지워짐** (일일 확률) / ≥75 T2도 대상 / ≥90 파편 부족해도 3막 강제 개방 |
| `HV_ORTEN_PULL` 오르텐의 유혹 | 0~10 | 2 | 일지 필사 +3, 파편 3개 +1, 선창자 대면 시 호기심 선택 +2, `AF_NELL_ORTEN <= -3` +2 | `MEAL_2A` 완료 −2, 3막 전 오르텐과 개인 대화 −2 | `EV_3_06`에서 판정 (§15-2) |
| `HV_BRAM_DESPAIR` 브람의 절망 | 0~10 | 2 | 리나 장면에서 "아무것도 없다" 선택 +3, 넬 연행 +2, 야영 식사 스킵 +1/회 | 식사 이벤트 참여 −1/회, 물증 3개 모두 제시 −2 | `EV_2_N01`에서 ≥7이면 끈을 새김 |
| `HV_NELL_VENGEANCE` 넬의 복수심 | 0~10 | 4 | 신도 의식 목격 +2, 에드릭 생존·발각 +3, 밀약 목격 +1 | `AF_PLAYER_NELL >= 6` −2, 몽석 소각의 밤 −3 | ≥7이면 `EV_3_03` 직전 **넬이 감옥의 에드릭을 살해 시도** |
| `HV_TRAIT[n]` 개인 성향 | 각 0~1 | 시드 랜덤 | — | — | 주민별 {신앙심, 겁, 공격성, 충성}. §14 판정에 사용 |
| `HV_RUMOR` 소문 큐 | 목록 | 비어 있음 | 사건 발생 시 생성 | 시간 경과로 소멸 | §14-6 |

- 숨은 변수들은 서로 연결된다. 예: 공포도 ↑ → 입교 ↑(교단 세력) → 암살 ↑ → 사망 ↑ → 공포도 ↑ (악순환)
- **이해도와 의심도의 숨은 트레이드오프**: 엔딩 B로 가는 행동(동전, 유생체, 일지)은 수도회의 의심을 올린다. 진실에 다가갈수록 세계가 파티를 적대한다 = "알수록 무거워진다"의 시스템화.

### 13-3. 플레이어가 보는 신호 (수치 대신)

| 변수 | 낮을 때 | 높을 때 |
|------|---------|---------|
| `HV_FEAR` | 축제 분위기, 아이들이 뛰어놂 | 문이 닫힘, "해 지면 나가지 마쇼", 창문에 판자 |
| `HV_CHOIR` | 조용한 밤 | 벽의 소용돌이 낙서 증가, 밤마다 먼 노랫소리 |
| `HV_SUSPICION` | 병사들이 무관심 | 병사가 파티를 따라다님. 하델: "심문관님이 파티 서류를 전부 사본으로 가져가셨습니다" |
| `HV_STIR` | 평소 몬스터 수 | 몬스터 증가. 여관 식탁에 **아무도 앉지 않은 빈 의자**가 늘어난다 (지워진 사람의 자리) |
| `HV_ORTEN_PULL` | 오르텐이 브람과 투닥거림 | 밤에 혼자 중얼거림, 필사본을 숨김 |
| `HV_BRAM_DESPAIR` | 요리 버프 정상 | **요리 품질 저하 → 식사 버프 감소**, 대사가 짧아짐 |
| `HV_NELL_VENGEANCE` | 넬이 농담에 반응 | 야영지에서 칼을 간다, 에드릭 이름에 침묵 |

## 14. NPC 자율 행동과 PK

### 14-1. 원칙
- 주인공을 제외한 **모든 NPC는 다른 NPC를 해칠 수 있다** (보호 등급 §2-5 범위 내).
- 해치는 행동은 반드시 **동기 테이블(§14-3)** 중 하나에 근거한다. 무작위 살인 없음.
- 플레이어가 없는 곳에서도 일어난다 (오프스크린). 플레이어는 시체, 소문, 빈 의자로 사후에 안다.
- 플레이어가 현장에 있으면 **막기 / 방관 / 가담**을 선택할 수 있다.

### 14-2. NPC 행동 상태
`일상 → 경계 → 적대 → 공격 → (도주 | 체포 | 사망)`
- 상태 전이는 동기 점수와 기회 점수로 결정 (§14-7 공식).

### 14-3. 동기 테이블

| 가해자 | 대상 | 발동 조건 | 행동 | 비고 |
|--------|------|-----------|------|------|
| 수도회 병사 | 정체가 드러난 신도 | 항상 | 체포 (`HV_SUSPICION >= 90`이면 즉결 처형) | 이졸데는 공개 재판 선호 |
| 수도회 병사 | 파티원 | `HV_SUSPICION >= 90` | 체포/공격 | — |
| 교단 신도 | 밀고자, 정체를 아는 주민, 수도회 병사 | `HV_CHOIR >= 70`, 야간, 대상 단독 | 암살 | 시체를 유적 근처에 버림 (`HV_STIR` 상승) |
| 교단 신도 | 지워진 자 | 의식에 쓸모없어졌을 때 | 처분 | R6: 아무도 모름 |
| 자경단(주민) | 소문 점수 최고 인물 | `HV_FEAR >= 60` | 린치 시도 | **틀린 소문이면 무고한 사람이 죽는다.** 마르타(레드 헤링)가 표적이 될 수 있음 |
| 유족 | 가해자로 **지목된** 자 | 원한 기록 존재, `HV_TRAIT.공격성 >= 0.5` | 복수 | 지목이 틀렸으면 연쇄 원한 |
| 넬 | 에드릭, 교단 사제 | `HV_NELL_VENGEANCE >= 7` | 살해 시도 | 플레이어가 동행 시 제지 선택 가능 |
| 이졸데 | 넬 (연행 시) | 연행 상태 && `HV_SUSPICION >= 70` && 3막 전 미구출 | 처형 | §15-2 |
| 성가대 ↔ 수도회 | 서로 | 조우 시 | 교전 | 3자 교전 |
| 몬스터 | 누구나 | 서식지 진입 | 공격 | `HV_STIR`로 서식 범위 확대 |

### 14-4. 인식 제약 (R3 / R6)
- 물든 NPC는 지워진 자를 **공격·목격·기억할 수 없다.**
- 지워진 자가 죽어도 원한/소문/공포가 생기지 않는다. 기억하는 건 주인공과 끈 보유자(넬, 에드릭)뿐.
- 반대로 **지워진 자는 물든 NPC를 해칠 수 있다** (보이지 않는 가해자). 단, 지워진 자 중 가해 동기를 가진 건 교단에 세뇌된 경우뿐이며 3막 사원 구역에서만 발생.

### 14-5. 사망의 파급
사망 1건이 발생하면 다음을 순서대로 처리한다.
1. **시체** 생성 (허브라면 다음 날 아침 발견 이벤트)
2. **목격자 기억**: 현장 NPC가 `{가해자, 피해자, 시각}` 기록 (`CanPerceive` 필터)
3. **소문** 생성: 목격자가 있으면 정확도 높음, 없으면 소문이 임의 인물을 지목 (의심 요소: 외지인, 수상한 행동 이력, 잠입 신도 여부)
4. **공포도** 상승
5. **유족 원한** 기록 (§2-6 가족 관계)
6. **세력 수치** 조정 (신도 사망 → `HV_CHOIR` 감소 등)
7. **역할 대체** 확인 (T2라면 §15-1)

### 14-6. 소문 시스템
- 소문 = `{사건ID, 지목된 인물, 정확도(0~1), 전파 횟수}`
- 매 틱마다 소문 허브(여관 주인, 하델, 시장 상인)를 거쳐 퍼진다. 전파될수록 정확도가 떨어질 수 있다.
- 플레이어는 소문을 **듣는 것**으로만 오프스크린 사건을 안다. 진범을 밝혀 소문을 바로잡으면 린치/복수를 막을 수 있다 (조사 = 개입).
- 소문 점수가 가장 높은 인물이 자경단의 표적이 된다. **주인공도 표적이 될 수 있다** (외지인). 주인공은 T0이므로 사망하지 않고 "투옥/추방 위기" 이벤트로 처리.

### 14-7. 시뮬레이션 방식

**오프스크린 (월드 틱)**
- 하루 2회 (아침/밤) 실행. 허브 귀환, 야영, 지역 이동 시 경과 시간만큼 몰아서 실행.
- 각 틱에서: 숨은 변수 갱신 → 동기 판정 → 사건 발생 → 파급 처리 → 소문 전파.

**온스크린 (실시간)**
- 플레이어 화면 안의 NPC는 실시간 AI로 동일한 동기 테이블을 따른다.
- 사건 직전 경고 신호 (언성, 무기 뽑기) → 플레이어 개입 여지.

**공격 발생 확률 (제안 공식)**
```
motive      = 동기 테이블 기본값 (0~1)
aggression  = HV_TRAIT[attacker].공격성
opportunity = (야간 ? 1.5 : 1.0) * (대상 단독 ? 1.5 : 0.5)
deterrence  = 경비 수 * 0.2 + (파티 동행 ? 0.8 : 0)
P(attack)   = clamp(motive * (0.5 + aggression) * opportunity - deterrence, 0, 0.9)
```
- 수치는 밸런싱용 초안. 상수로 빼서 조정한다.

**권장 에이전트 구조 (제안)**
```cpp
struct NpcAgent {
    CharacterId id;
    ProtectionTier tier;        // §2-5
    FactionId   faction;
    Traits      traits;         // 신앙심, 겁, 공격성, 충성 (시드 랜덤)
    AgentState  state;          // 일상/경계/적대/공격/...
    std::vector<Grudge>  grudges;   // {대상, 강도, 원인 사건}
    std::vector<Witness> memories;  // {사건, 가해자, 피해자}
    bool isCovertCultist;       // 잠입 신도 (§2-6)
    bool alive = true;
};

struct HiddenState {            // StoryState와 분리, UI 비노출
    int fear, choir, suspicion, stir;
    int ortenPull, bramDespair, nellVengeance;
    std::vector<Rumor> rumors;
    uint32_t rngSeed;
```

## 15. 역할 대체 & 분기 확장

NPC가 죽어도 메인 스토리가 막히지 않게 한다. 대신 **누가 그 역할을 했는지에 따라 장면과 결과가 달라진다.**

### 15-1. 역할 대체 표

| 스토리 역할 (이벤트) | 1순위 | 2순위 | 3순위 | 전원 부재 시 |
|----------------------|-------|-------|-------|--------------|
| 이빨 자국 부자연스러움 지적 (`EV_1_02`) | 고드윈 | 넬 | — | 주인공이 도감 관찰로 직접 발견 |
| 수도회를 부르는 보고 (`EV_2_G01`) | 하델 (규정 보고) | 여관 주인 (소문) | — | `HV_STIR >= 50`을 수도회가 자체 감지해 도착 (2일 지연) |
| 넬 정체 폭로 (`EV_2_G02`) | 이졸데 | 테오 | 소문 | 넬이 스스로 고백 (브람 반응 완화, `AF_BRAM_NELL -2`만) |

| 3막 수도회 저지 (`EV_3_02`) | 테오 | — | — | 수도회 전력 온존 → 사원 진입 시 추격전 |
| 이졸데 사망 시 | 테오가 지휘관 승계 | — | — | 테오 지휘 시 **정화 작전 취소** (`HV_SUSPICION < 70`일 때) |

| 유생체 선택 (`CH_2A_LARVA`) | 약초꾼 노파 | — | — | 노파 사망 시 "살려 둠" 선택지 소멸 (이해도 경로 축소) |

### 15-2. 동료의 숨은 운명 (T1 예외 규칙)

| 동료 | 결과 | 조건 (플레이어 비공개) | 연출 |
|------|------|------------------------|------|
| 넬 | **처형** | `!FL_NELL_TRUSTED` && `HV_SUSPICION >= 70` && 3막 전 수도회 야영지 구출 미실행 | 3막 `EV_3_04` 대신 넬의 흉터 자국만 남은 처형대 발견. 모든 엔딩에서 넬 에필로그 제거 |
| 넬 | **에드릭 살해** | `HV_NELL_VENGEANCE >= 7` && 플레이어 제지 실패/방관 | 에드릭 사망 → 길잡이 대체 표 적용. 넬은 파티에 남지만 `AF_PLAYER_NELL`에 따라 대사 변화 |
| 오르텐 | **배신** | `EV_3_06`에서 `HV_ORTEN_PULL >= 7` && `AF_PLAYER_ORTEN < 3` | 오르텐이 선창자 편으로 넘어감 → 선창자전에 **오르텐이 합창 보조로 등장** (처치 or 설득). 설득 조건: 넬 생존 && `AF_NELL_ORTEN >= 2` |
| 오르텐 | 배신 후 사망 | 선창자전에서 설득 실패 | 이름의 전문을 듣고 지워짐. 주인공만 기억 |
| 브람 | 끈을 새김 | `HV_BRAM_DESPAIR >= 7` (§5-3) | 사망/이탈 없음. 엔딩 A 변형 |

- 오르텐 배신 시 엔딩 B의 "일지 불태우기" 장면은 사라지고, 파수꾼 "듣기"의 조건(`FL_JOURNAL_READ`)은 유지된다.

### 15-3. 엔딩 D — 노래가 끝나지 않는 밤 (숨은 엔딩)

- **조건**: 3막 조수 제한 시간 초과 (게임 오버 대신 이 엔딩으로 진입)
  - 제한 시간은 `HV_CHOIR >= 90`(−30%), 길잡이 부재(−20%)로 줄어든다 → 숨은 변수가 이 엔딩의 실질적 원인.
- **내용**: 선창자가 이름을 완성하고, 물들지 않은 주인공을 그릇으로 삼는다. 주인공은 이름을 쥔 채 세상의 기억에서 지워진다.
- **에필로그**: 다음 해 추수 축제. 새로운 외지인이 길드에 등록한다. 회색 외투의 손님이 그에게만 말을 건다.
  "노래를 배우지 마시오."
  → 주인공이 카엘의 자리에 선다. 서장으로 이어지는 순환 구조.
- 이 엔딩은 선택지로 고를 수 없다. 존재 자체를 UI에 암시하지 않는다.

### 15-4. 숨은 변수 · 생존 상태에 따른 에필로그 변형

| 조건 | 적용 엔딩 | 변형 |
|------|-----------|------|
| T3 주민 생존율 < 50% | 전체 | 라벤홀 장면이 폐허에 가깝게. 축제가 열리지 않음 |
| 마르타 사망 (린치) | 전체 | 에필로그에 "잘못 지목된 원로"의 묘비. 소문으로 죽은 사람이 있었다는 사실만 남음 |
| 넬 사망 | A | 모든 것을 기억하는 사람이 아무도 없는 A. 갈림길 장면에 아무도 없다 |
| 이졸데 생존 && `HV_SUSPICION < 30` && B | B | 이졸데가 파수꾼(주인공)의 기록자가 되어 사원 입구를 지킨다 |
| 이졸데 사망 && 테오 지휘 | 전체 | 수도회가 라벤홀에서 철수. C에서도 정화 확대 없음 |

| 오르텐 배신 후 설득 성공 | B | 오르텐이 일지 대신 **자기 필사본과 이름 지식을 스스로 잊는 의식**을 치름 |
| 하델 사망 | C | 마지막 대사 화자 교체 (§15-1) |
| `HV_STIR >= 75` 도달 이력 | B | 돌아오는 지워진 자 명단에 **플레이어가 모르던 이름들**이 섞여 있다 (오프스크린으로 지워졌던 주민들) |
