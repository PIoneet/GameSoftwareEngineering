--------------------------------------------------------------------
1. 프로젝트 개요
--------------------------------------------------------------------

- 출발점: 수업(Game Software Engineering, KPU)에서 배포한 C++/OpenGL
  베이스 프로젝트("SimpleGame")
- 현재 코드베이스: GLEW + FreeGLUT 기반 최소 렌더러 스켈레톤.
  Renderer 클래스가 셰이더 컴파일/VBO 생성/사각형 그리기를 담당
  (SimpleGame/Renderer.h, SimpleGame/Renderer.cpp),
  main()은 GLUT 콜백만 등록된 상태 (SimpleGame/SimpleGame.cpp).
- 저장소: https://github.com/PIoneet/GameSoftwareEngineering.git (master 브랜치)
- 목표: 이 스켈레톤을 확장해 실시간 렌더링 기반의 오픈월드 RPG를 제작한다.

--------------------------------------------------------------------
2. 게임 디자인 목표
--------------------------------------------------------------------

  장르       : 오픈월드 RPG
  시점       : 쿼터뷰(quarter-view), 2.5D로 표현
  구현 방식  : 2D 스프라이트 + 아이소메트릭 수식
               (진짜 3D 카메라/MVP 행렬 아님)
               - world(x,y,z)를 CPU에서 화면 좌표로 변환
               - 깊이 정렬은 GL_DEPTH_TEST가 아니라
                 painter's algorithm(그리기 순서 정렬)으로 처리
  플레이 인원: 싱글 플레이 전용 - 네트워킹/서버 동기화 불필요
  렌더링     : 실시간(real-time) - 프레임마다 Update(dt) -> Render()
               루프 필요 (현재 코드엔 아직 없음, 추가 예정)

--------------------------------------------------------------------
3. 세계관 / 스토리 바이블
--------------------------------------------------------------------

- 시간적 배경: 중세 판타지
- 분위기(톤): 다크하지만 군데군데 유머가 섞임
  (예: 길드 서기의 관료주의 개그, 동료 NPC의 드립)
- 스토리 축: 미지의 존재를 조금씩 알아가는 코즈믹 호러
  - 크툴루 신화 오마주. "알수록 무거워지는 진실" 모티프.
- 전투/던전 설계 철학: 던전밥(던전 밥) 스타일
  - 몬스터를 단순 스탯 덩어리가 아니라 각자 고유한 생태·행동 패턴·
    공략법(counter-strategy)을 가진 대상으로 설계.
  - 데이터 기반 베스티어리(종류별 스탯+행동+공략법) 구조를 지향.
- 작업 타이틀: "잠든 것의 이름" (가제 - 변경 가능)

  [메인 퀘스트 트리 (초안 v0.1)]

  - 서장 - 이방인의 밤
    축제 밤, 낯선 손님 등장 + 슬라임 소탕 첫 의뢰.
    손님이 남긴 소용돌이 문양 동전(첫 단서).

  - 1막 - 이빨 자국
    실종 사건 조사, 첫 던전(채석장). 초커/아이볼 등장.
    문양 재발견.

  - 2막 - 잠들지 않는 자들의 노래
    오픈월드 자유 탐사(3개 지역, 순서 무관).
    사이비 신도/촉수 유생체 등장. 원로의 배신 밝혀짐.

  - 3막 - 이름 없는 것의 그림자
    최종 던전(가라앉은 사원), 3페이즈 보스 "심연의 파수꾼".
    존재의 정체가 "파괴자가 아니라 잊히길 원하는 무언가"임이 드러남.

  - 파이널 - 잠든 것의 이름을 부르다
    3분기 엔딩 - 봉인(A) / 이해(B) / 파괴(C)

  ※ 상세 내용은 발행된 아이디어 아트팩트("잠든 것의 이름 - 메인
     퀘스트 트리") 참고. 지역/던전 개수, 분기 조건 등 세부는 추후
     리비전에서 구체화 예정.

4. 기술적으로 풀어야 할 것 (진행하며 구체화)
--------------------------------------------------------------------

- 게임 루프 뼈대: 현재 Idle()이 RenderScene()만 호출하는 구조
  -> 델타타임 계산 + Update(dt)/Render() 분리 필요
- 쿼터뷰 투영: world(x,y,z) -> screen 좌표 변환 공식 정립
  예) screenX = (x-y) * tileW/2
      screenY = (x+y) * tileH/2 - z
- 깊이 정렬: 매 프레임 오브젝트를 painter's algorithm으로 정렬 후 그리기
- 셰이더/Renderer 확장: 현재 DrawSolidRect 하나뿐인 구조를 여러
  오브젝트(스프라이트) 순회 렌더링 구조로 확장
- 알려진 버그: CompileShaders 실패 시 -1을 GLuint로 반환해 실패가
  은폐되는 문제 (Renderer.cpp) - 조만간 수정 필요
- 오픈월드 규모: 카메라 스크롤/월드 스트리밍, NPC·퀘스트·인벤토리
  시스템 등은 스펙 확정 후 설계

--------------------------------------------------------------------
5. 협업 규칙
--------------------------------------------------------------------

- 빌드/실행 확인은 사용자가 직접 진행. 특별한 이유(사용자 요청,
  빌드 에러 디버깅 등)가 없으면 Claude는 코드 수정까지만 하고
  빌드/실행을 시도하지 않는다.
- 요구사항은 한 번에 몰아서 주지 않고 순차적으로 추가되는 경우가
  많음 - 사용자가 "더 말씀드릴게요"라고 하면 구현에 들어가지 않고
  스펙을 계속 수집한다.
